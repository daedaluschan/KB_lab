## 加入新項目

- 喺適合嘅目的地表格新增一行。
- 「已買」欄使用 `- [ ]`；買咗之後改為 `- [x]`。
- 「擁有人」使用：Dad、Mom 或 Jinny。
- 如有相片，使用 Markdown 圖片語法，例如 `![物品名稱](../assets/images/travel-shopping/item-name.jpg)`；沒有相片則保留 `—`。
