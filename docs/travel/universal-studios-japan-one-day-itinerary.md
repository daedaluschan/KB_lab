# Universal Studios Japan 一日攻略

## Express Pass 8：10:30 入 SUPER NINTENDO WORLD 版本

呢份行程適合已經買咗 **Express Pass 8**，而且指定 **10:30 入 SUPER NINTENDO WORLD**、並喺指定時段玩 Mario、Donkey Kong、Harry Potter 同 Minion 項目嘅一日遊。

!!! tip "核心策略"
    早上唔好浪費時間。**10:30–12:00 專心完成 Mario + Donkey Kong**，下午先慢慢行、影相、食嘢同買手信。

## 指定 Express Pass 時間表

| 時間 | 項目 |
| --- | --- |
| 10:30–11:30 | SUPER NINTENDO WORLD 入場 |
| 10:30–11:00 | Mario Kart: Koopa’s Challenge |
| 11:00–11:30 | Yoshi’s Adventure |
| 11:30–12:00 | Mine Cart Madness |
| 13:50–14:20 | Flight of the Hippogriff |
| 15:00–15:30 | Illumination’s Villain-Con Minion Blast |

## 入園前一晚準備

- 下載 **USJ 官方 app**。
- 下載或截圖所有門票同 QR code：
  - Studio Pass 入場票
  - Express Pass
  - 每個人嘅 QR code
- 檢查當日資訊：
  - 開園時間
  - 停運項目
  - Show / parade 時間
- 帶備以下物品：
  - Power bank
  - 小水樽
  - 雨衣或薄外套
  - 細零食
  - 舒服鞋

## 當日路線

### 早上：盡早到達

建議 **開園前 60–90 分鐘到 USJ 門口**。

入園後唔好先買手信，亦唔好慢慢影相。趁早上人流相對少，先玩一個無指定時間嘅熱門項目。

=== "家庭穩陣版"

    - Harry Potter and the Forbidden Journey
    - JAWS
    - Jurassic Park – The Ride

=== "刺激版"

    - Hollywood Dream
    - The Flying Dinosaur

!!! important "時間提醒"
    **10:15 左右要開始行去 SUPER NINTENDO WORLD 入口附近**，預留時間入區同處理人流。

### 10:30–12:00：SUPER NINTENDO WORLD 黃金時段

呢段時間最重要，唔好安排食飯、買手帶或者慢慢影相。

| 時間 | 行動 |
| --- | --- |
| 10:20 | 到 SUPER NINTENDO WORLD 入口附近等入場 |
| 10:30–11:00 | 玩 **Mario Kart: Koopa’s Challenge** |
| 11:00–11:30 | 玩 **Yoshi’s Adventure** |
| 11:30–12:00 | 玩 **Mine Cart Madness** |

### 12:00–12:30：留喺 Nintendo World

三個 ride 玩完之後，可以開始慢慢享受 Mario 區：

- 拍照
- 買 Power-Up Band
- 玩小遊戲
- 買 Mario / Donkey Kong 手信
- 睇環境同打卡位

!!! note "Power-Up Band 建議"
    Power-Up Band 最好 **12:00 後先買**，因為 10:30–12:00 時間太緊，唔值得分散注意力。

### 12:30–13:30：午餐 + 移動去 Harry Potter 區

13:50 要玩 **Flight of the Hippogriff**，所以午餐唔好排太耐。

建議選擇：

- 喺 Harry Potter 區附近食飯
- Quick service 快餐
- 小食 + 飲品

如果 **Three Broomsticks** 人唔多，可以食；如果排隊太長，就唔好等，避免影響下一個 Express 時間。

| 時間 | 行動 |
| --- | --- |
| 13:30–13:40 | 去 **Flight of the Hippogriff** 附近等 |

### 13:50–14:20：Flight of the Hippogriff

呢個係家庭版過山車，唔算太恐怖。

玩完可以喺 Harry Potter 區補影相：

- Hogwarts 城堡
- Hogsmeade 街景
- Butterbeer
- 商店

但唔好留太耐，因為 15:00 要去 Minion 區。

### 14:20–14:50：移動去 Minion Park

呢段時間用嚟：

- 行去 Minion Park
- 去洗手間
- 買飲品
- 影 Minion 區相

| 時間 | 行動 |
| --- | --- |
| 14:50 | 到 **Illumination’s Villain-Con Minion Blast** 附近等 |

### 15:00–15:30：Illumination’s Villain-Con Minion Blast

玩完之後，主要指定時間項目已經完成，之後可以自由安排。

## 15:30 之後：自由時間

下午可以補玩 Express 8 入面其他無指定時間嘅項目。

建議優先次序：

1. **Harry Potter and the Forbidden Journey**  
   如果上午未玩，下午一定補玩。
2. **JAWS / Jurassic Park – The Ride**  
   想輕鬆就揀 JAWS；想刺激就揀 Jurassic Park。
3. **Despicable Me Minion Mayhem / Hollywood Dream / The Flying Dinosaur**  
   視乎你嘅 Express Pass 包邊一個，以及小朋友是否夠高同敢玩。
4. **睇 Parade / Show**
5. **買手信**

## 餐飲安排

按照已選嘅 Express Pass 時間表，當日行程其實幾緊湊：

| 時間 | 活動 |
| --- | --- |
| 10:30–12:00 | SUPER NINTENDO WORLD |
| 13:50–14:20 | Flight of the Hippogriff |
| 15:00–15:30 | Illumination’s Villain-Con Minion Blast |

所以，**唔建議喺中午時段預約全服務餐廳**。最好喺主題區入面食，慳返行路時間，同時可以更投入園區氣氛。

### 可使用 Priority Seating 嘅餐廳

USJ 目前只有兩間餐廳提供 **Priority Seating**，而且呢個唔係保證訂枱。意思係你會喺所選時段附近，優先安排下一張可用枱；繁忙日子仍然可能要等一陣。

Priority Seating 通常開放時間：

- 到訪日前 **1 個月**
- 日本時間 **11:00 JST**
- 最遲可於到訪前 **24 小時**預約，視乎供應情況

#### Park Side Grille ⭐⭐⭐⭐☆

**位置：** New York Area

**菜式：** steak、burgers、seafood、Western cuisine。

**優點：**

- USJ 園內氣氛最好嘅餐廳之一
- 座位舒服
- 適合特別場合
- 可安排 birthday cakes

**缺點：**

- 離 SUPER NINTENDO WORLD 同 Harry Potter 區較遠
- 會佔用較多行程時間

**適合：** 大人想食一餐舒服午餐，或者當日行程比較慢。

#### SAIDO ⭐⭐⭐⭐☆

**位置：** New York Area

**菜式：** Japanese set meals、sushi、tempura、seasonal dishes。

**優點：**

- 環境較安靜
- 適合家庭
- 日式餐品質素唔錯

**缺點：**

- 一樣需要離開主要遊樂區域

**適合：** 想食日式料理，或者想搵一個安靜啲嘅用餐地方。

### 建議餐飲路線

#### 🍄 午餐：Kinopio’s Cafe / Toad Cafe ★★★★★

**位置：** SUPER NINTENDO WORLD

**建議時間：** **12:00–12:40**

點解適合：

- 啱啱完成 SUPER NINTENDO WORLD 三個 Express 項目
- 唔需要離開 Nintendo World
- 日本最受歡迎嘅主題餐廳之一

建議餐點：

- Mario Burger
- Super Mushroom Soup
- Question Block Tiramisu
- Peach Cake
- Mario drinks

!!! tip "Kinopio’s Cafe 排隊策略"
    好多遊客一入 SUPER NINTENDO WORLD 就會即刻排隊食 Kinopio’s Cafe。呢份行程先玩遊樂設施，所以大約中午先排，通常會比較合理。

#### 🍺 下午小食：Three Broomsticks ★★★★★

**位置：** Wizarding World of Harry Potter

**建議時間：** **14:20–14:50**

建議餐點：

- Butterbeer
- Roast Chicken Platter
- Shepherd’s Pie
- Fish & Chips

可以享受：

- Hogwarts Castle 景觀
- Hogsmeade 氣氛
- 好多影相機會

#### 🍌 Minion Blast 後小食休息

玩完 **Illumination’s Villain-Con Minion Blast** 之後，可以揀快手小食：

- Popcorn
- Minion cookies
- Churros
- Ice cream

### 晚餐：Universal CityWalk Osaka

主要指定時間項目喺下午較後時間已經完成，所以建議晚餐去園外 **Universal CityWalk Osaka** 食。

優點：

- 餐廳選擇更多
- 性價比通常較好
- 無園內咁迫
- 唔需要趕返去玩指定時間項目

建議餐廳：

- Kua’Aina Burger
- Botejyu
- TGI Fridays
- Shabu-Yo
- Ganko Sushi
- Starbucks，適合返去前坐低休息

!!! recommendation "呢份行程嘅最佳餐飲建議"
    呢個時間表建議唔去 Park Side Grille 同 SAIDO。午餐食 **Kinopio’s Cafe**，下午去 **Three Broomsticks** 飲 Butterbeer，喺 Minion Park 食小食，晚餐去 **Universal CityWalk Osaka**。

## 最重要提醒

### 10:30–12:00 唔好分心

呢個 Express Pass 最值錢嘅部分係：

**Mario Kart → Yoshi’s Adventure → Mine Cart Madness**

所以呢段時間唔好：

- 食飯
- 買手帶
- 買手信
- 排其他隊
- 慢慢影相

全部留到 12:00 後先做。
